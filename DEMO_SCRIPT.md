# Demo script (about two minutes; 3–5 minutes if you add limits)

Public app path: Overview → search `BDA-2024-05307` → review → Export. Repository: https://github.com/Run-Disc/HomeSignal

Record the running app. Do not narrate features that are not present. Fill `[your name]` yourself.

0:00–0:20 Overview  
“This is my submission to the AI for Housing Hackathon, part of AI Horizons 2026. I’m [your name]. HomeSignal helps a housing analyst review evidence in Pittsburgh permit descriptions. A permit record is not a completed home.” Point to the on-screen **Two-minute judge path**.

0:20–0:40 Source scope  
Show snapshot date 2026-09-26, 4,243 issued 2025 Building/BDA records, 727 candidates, blank-description count, and Sources. State that commercial class is included because it can contain housing.

0:40–1:10 Real commercial-class housing language  
Open `BDA-2024-05307` (Middle Hill, Commercial): “TOTAL OF 12 DWELLING UNITS ABOVE.” Say this is proposed-unit language on an issued permit, not proof of occupied homes.

1:10–1:30 Extraction honesty  
If the status says AI is not configured, **read that sentence**. Do not click around waiting for a spinner. Manual source review still works. Do not describe a missing call as live AI.

1:30–1:50 Human review  
Correct or mark insufficient evidence. Show the review badge and return to overview so Needs review / Reviewed counts change.

1:50–2:10 Export  
Open Export briefing. Show record counts, the permit-is-not-a-unit limitation, and Print or CSV.

Optional extra 30–60 seconds: `BDA-2025-01572` ambiguous “32 UNIT DWELLINGS” / “NO WORK”; comparison record `BDA-2024-01477`; Evaluation page (labels not filled; no accuracy %).

Do not say the City validated this, the model is 99% accurate, a host is live unless you verified it, or that you found N homes built.

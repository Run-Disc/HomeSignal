# Demo script (3–5 minutes)

Record the running app. Do not narrate features that are not present. Fill `[your name]` yourself.

0:00–0:20 Overview  
“This is my submission to the AI for Housing Hackathon, part of AI Horizons 2026. I’m [your name]. HomeSignal helps a housing analyst review evidence in Pittsburgh permit descriptions. A permit record is not a completed home.”

0:20–0:45 Source scope  
Show snapshot date 2026-09-26, 4,243 issued 2025 Building/BDA records, 727 candidates, blank-description count, and Sources. State that commercial class is included because it can contain housing.

0:45–1:15 Real commercial-class housing language  
Open `BDA-2024-05307` (Middle Hill, Commercial): “TOTAL OF 12 DWELLING UNITS ABOVE.” Say this is proposed-unit language on an issued permit, not proof of occupied homes.

1:15–2:00 Extraction  
Click Ask AI. **If the banner says extraction unavailable, say that plainly.** Manual source review still works. Do not describe a missing call as live AI. If a previously generated response exists, say “Previously generated” and read the original timestamp.

2:00–2:35 Human review  
Accept, correct, or mark insufficient evidence. Show the review badge and return to overview so Needs review / Reviewed counts change.

2:35–3:00 Ambiguous case  
Open `BDA-2025-01572` (Marshall-Shadeland): “NO WORK - CORRECTION … 32 UNIT DWELLINGS.” Leave proposed units unknown unless the description explicitly says what the number is doing. Show `BDA-2024-01477` or another comparison record as likely non-housing office work.

3:00–3:30 Export  
Open Export briefing. Show filters, record counts, evidence quotes, next verification (analyst / permit staff / OneStopPGH), and limitations. Save as PDF or CSV.

3:30–4:00 Limits  
No citywide homes-built total. Evaluation labels are not yet independently completed. Unconfirmed next step: one analyst reviews a bounded set and compares time and agreement with source-only review. No agency has agreed to a pilot.

Do not say the City validated this, the model is 99% accurate, or that you found N homes built.
